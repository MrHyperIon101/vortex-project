Vortex - A Premium BitTorrent Client in Qt
------------------------------------------

Vortex is a fast, stable, lightweight, and feature-rich BitTorrent client programmed in C++ / Qt, powered by the `libtorrent` library. It aims to be a premium, modern, and open-source alternative to other torrent clients, providing a clean user experience with no ads, trackers, or hidden costs.

### Key Features:

*   **Polished Qt User Interface**: Clean, intuitive layout designed for ease of use.
*   **Integrated Search Engine**: Extensible Python-based search allowing simultaneous queries across multiple popular torrent sites.
*   **RSS Auto-Downloader**: Built-in RSS feed reader and automated downloader with advanced regex filters.
*   **Bandwidth Control**: Granular global and per-torrent speed limits, including a flexible bandwidth scheduler.
*   **Protocol Support**: Full compatibility with BitTorrent extensions including DHT, Peer Exchange (PeX), Local Service Discovery (LSD), Magnet links, µTP connection protocol, and protocol encryption.
*   **Network & Security**: Interface binding (to prevent VPN traffic leaks), SOCKS5/HTTP proxy support, and IP filtering (eMule `.dat` or PeerGuardian format).
*   **Remote Control (Web UI)**: Responsive, password-secured Web UI mimicking the desktop interface for managing downloads from any browser.
*   **Automation & Notifications**: Email alerts on completion, power management options (suspend/shutdown), and hooks to run external programs on torrent events.
